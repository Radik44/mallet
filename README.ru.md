# Mallet

<p align="center"><img src="brand/mallet.png" width="128" alt="Mallet"></p>

**Mallet - современный редактор карт для Garry's Mod и других игр на Source: те же VMF и те же компиляторы, что у Hammer, но интерфейс из этого десятилетия.** Бесплатная программа с исходниками, открытая для тестировщиков: перед вами **демо 0.1**, сырое и выпущенное именно для проверки на настоящих картах.

[English version](README.md)

Редактор задуман как полная замена Hammer и Hammer++. Исходник карты остаётся VMF, сборка идёт
штатными vbsp, vvis и vrad из поставки GMod; интерфейс в духе Unity и Unreal, понятный новичку,
с обучением на первом запуске.

## Системные требования

| | Минимум |
| --- | --- |
| Система | Windows 10 (1809 и новее) или Windows 11, 64-бит |
| Графика | Видеокарта и драйвер с поддержкой Direct3D 12 (Mallet рисует через WebGPU; встроенная графика с 2016 года подходит) |
| Память | 4 ГБ ОЗУ; для больших карт лучше 8 ГБ |
| Диск | 30 МБ на редактор и несколько сотен МБ кэша текстур и моделей игры |
| Игра | Garry's Mod, установленный через Steam: текстуры, модели, звуки и компиляторы (vbsp, vvis, vrad) читаются из вашей копии; без игры редактор работает, но без её контента |
| Среда | Microsoft Edge WebView2 - идёт в установщике, ставить отдельно ничего не нужно |
| Ассистент (по желанию) | Интернет и либо подписка Claude (Claude Code - компонент установщика и кнопка в настройках ассистента), либо API-ключ Anthropic |

Node.js, Python и другие инструменты разработчика для работы Mallet не нужны. Установщик не требует прав администратора.

## Установка

1. Скачайте `Mallet_<версия>_x64-setup.exe` со страницы [последнего выпуска](https://github.com/Radik44/mallet/releases/latest).
2. Запустите. Установщик пока не подписан, поэтому SmartScreen спросит один раз: *Подробнее → Выполнить в любом случае*.
3. Выберите язык установщика, прочитайте лицензию (кнопка **Далее** открывается через несколько секунд) и отметьте компоненты: редактор и WebView2 обязательны, **Ассистент: Claude Code** по желанию, его ставит официальный установщик Anthropic (интернет, около минуты). Редактор запустится на языке установщика.
4. Редактор сам найдёт Garry's Mod через Steam и загрузит контент игры. Прочитайте обращение автора, выберите урок для знающих Hammer, полное обучение или пропустите.

## Что умеет

- Четыре вида, как в Hammer, с докингом панелей, перетаскиванием видов и отдельными окнами.
- Браши, текстуры с предпросмотром при перетаскивании, энтити по FGD игры, дисплейсменты,
  инстансы, префабы, группы видимости, проверка проблем с автоисправлением.
- Инспектор как в Unity: трансформ с гизмо, пикеры цвета и углов, карточка света, выбор модели.
- Ландшафт кистью, как в Unreal: мастер делает площадку из сшитых дисплейсментов, кисть поднимает,
  сглаживает, выравнивает, кладёт шум и красит blend-альфу прямо в 3D-виде, через швы.
- Звуки: браузер звуков игры с прослушиванием и редактор: подрезка, петля с бесшовным кроссфейдом,
  громкость и fade, запись с микрофона, WAV 16 бит в проект карты, ambient_generic перетаскиванием.
- Рисовалка текстур: холст 64…1024 со слоями, кисть, карандаш, ластик, линия, прямоугольник,
  заливка, пипетка, текст, картинка или текстура игры слоем, бесшовный режим с плиткой 3×3,
  зеркало, VTF+VMT в проект карты с выбором шейдера и сразу на выделенные грани.
- Файл проекта `<карта>.mallet.json` рядом с VMF: цель карты из мастера, что собрано, проверено
  и протестировано; помощник видит это в сводке.
- Разбор сборки: знакомые ошибки лога (утечка, скайбокс, нет материала, сломанный браш, ошибки
  Lua в консоли игры) объясняются словами и чинятся одной кнопкой, остальное уходит помощнику
  вместе с логом по кнопке «Спросить помощника»; та же кнопка в «Проблемах».
- Взгляд из игры: снимки того, что видит игрок, прямо в редакторе, живой вид раз в секунду,
  тест-цикл «пересобрать и показать» одной кнопкой (сохранить, собрать, перезагрузить карту в
  игре или запустить её, поставить игрока в камеру редактора, снять), noclip и HUD с кнопок;
  помощник получает снимки как картинки и сам смотрит результат после правок; у него есть прямой
  доступ к игре: Lua в обоих мирах, консольные команды с выводом, луч, замер света, консоль без
  шума, снимок свободной камерой и серия кадров, причина выхода игры, поиск граней по материалу,
  проверка файлов и заголовков VTF, камера и снимок самого редактора.
- Звук перетаскивается из списка прямо в вид: появляется ambient_generic и карточка с громкостью,
  радиусом, петлёй и высотой, с прослушиванием.
- Ассистент Claude: чат, который по запросу строит браши и комнаты, ставит энтити и выходы, пишет
  Lua в проект карты (с подтверждением и дифом), собирает и запускает игру. Ответ печатается по
  мере прихода, каждый вызов инструмента появляется карточкой и выполняется сразу, панели и камеру
  он не трогает; к состоянию до любого шага можно вернуться, а в «Истории» его шаги помечены ✦.
  Работает через локальный Claude Code по подписке (редактор поднимает для него MCP-сервер со
  своими инструментами) или через ключ API из хранилища Windows (в окно редактора ключ не
  попадает).
- Сборка vbsp, vvis и vrad с разбором лога, утечками и порталами, упаковка контента в BSP,
  декомпиляция BSP обратно в VMF.
- Интерфейс на десяти языках (русский, английский, немецкий, французский, испанский,
  португальский, польский, турецкий, украинский, китайский, японский), включая ярлыки отмены и
  тексты проверок из ядра; тёмная и светлая темы.
- Запуск Garry's Mod на карте и живой мост с игрой: телепорт, камера, перенос энтити,
  сборка кубмапов одной кнопкой.
- Мастер первого запуска, полное обучение для новичка и короткий урок для знающих Hammer.

## Конфиденциальность и лицензия

Mallet не собирает телеметрию и сам ничего никуда не отправляет. Ассистент, когда и только когда
вы к нему обращаетесь, передаёт запрос, сводку карты и результаты инструментов сервисам Anthropic
на их условиях. Всё, что вы делаете в Mallet, принадлежит только вам. Программа бесплатна и должна
оставаться бесплатной: см. [LICENSE](LICENSE).

Garry's Mod, Source и Hammer принадлежат Facepunch Studios и Valve Corporation. Mallet -
независимый проект, не связанный с ними и не одобренный ими.

## Сборка из исходников

Нужны Rust stable с целью `wasm32-unknown-unknown`, Node.js 24 и pnpm 10, на Windows ещё Visual Studio Build Tools и WebView2.

```bash
pnpm install
pnpm dev
```

Установщик собирается командой `pnpm --filter @gme/editor tauri build --bundles nsis` и появляется в `target/release/bundle/nsis/`.
